常见问题

关于使用和技术的常见疑问解答

什么是进度流式体验？

本方案是进度流式（不是 token 流式）：实时可见 Agent 每次工具调用（搜索、读文件、写文件、生成 PDF），diff 预览功能让你看到文件修改内容。不过最终回复是一次性出现的，因为 Hermes CLI 内核不暴露 token 级流式。

如何自定义默认 profile？

可以通过两种方式修改：编辑 index.html 的 defaultCfg.profile，或者在运行时通过 ⚙️ 设置面板修改。支持使用任何已安装的 Hermes profile，如 default、hermes-research-report-agent 等。

已知限制有哪些？
  • 需先启动 server.py：服务常驻运行，浏览器才能访问
  • 任务历史是摘要式：本地只存「查询 + 回复前 100 字预览」
  • 文件上传不支持：如需 Agent 处理本地文件，把文件路径写进 prompt
  • 并发限制：每个任务启动一个 hermes 子进程，同时跑多个长任务会消耗较多资源

如何修改配色主题？

编辑 index.html :root 里的 CSS 变量来修改配色。主要颜色变量包括 --primary-color、--secondary-color 等。也可以在 Tailwind config 中自定义 brand 色系。

如何自定义 Hermes 命令参数？

编辑 server.py 的 run_hermes 函数里的 cmd 列表，可以添加 --max-turns、修改 model 等参数。比如加 --max-turns 10 来限制对话轮次，或 --model gpt-4 来更换模型。
